# Code of Conduct

Be decent. This is a project about looking after a small child; the tone here should
match.

Concretely: no harassment, no personal attacks, no dismissiveness towards people asking
beginner questions. Assume the person on the other side is tired — statistically, they
are.

Unacceptable behaviour can be reported to the maintainer via a private GitHub message.
Maintainers may remove comments or block accounts.

This is a condensed stand-in for the [Contributor Covenant](https://www.contributor-covenant.org/),
whose full text applies in spirit.
